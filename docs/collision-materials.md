# Collision materials (`materials.dat`)

The `material_type` stored in every collision polygon of a `.yft` / `.ybn` is an index into the game's own `materials.dat`: the entry's position in the file, counting only data lines, starting at 0. This page is that table, so a number from `yft_glass` can be read as a name.

Source: `update/update.rpf/common/data/materials/materials.dat` of the install (213 entries; the base `common.rpf` copy has the same count and the DLC `mpstunt` copy is a variant). Extracted with `rpf_extract`:

```bash
cargo build --release -p cw-core --example rpf_extract
./target/release/examples/rpf_extract.exe E:/Proyectos/_scratch/gta-data materials.dat materialfx.dat
```

The file itself is a Rockstar asset and is not committed. The tables below are only names and a few numbers from it. No page of <https://docs.fivem.net/docs/game-references/> covers materials, so the game file is the reference.

How the index was checked: `rrfaku.yft` uses types 116, 122 and 142, which read as `CAR_METAL`, `CAR_GLASS_STRONG` and `PHYS_CAR_VOID`, a car with resistant but not unbreakable glass. A different offset would not give that.

| 131 | `EMISSIVE_GLASS` | 1.0 | 1 0 0 0 | 0.2 / 0.6 |

Reading, with the legend at the top of the game file (SEE_THRU: AI probes pass through; SHOOT_THRU: weapon probes pass through; SHOOT_THRU_FX: report a collision on a shoot-thru polygon so VFX/SFX can play):

- `CAR_GLASS_BULLETPROOF` (123) is the only vehicle glass with a penetration resistance of 10000 and without the shoot-through flags (`1 0 0 0`; the others have `1 1 1 0`). It is the "never breaks" glass.
- `CAR_GLASS_WEAK`, `_MEDIUM` and `_STRONG` (120, 121, 122) are identical in this file except for elasticity (0.1, 0.2, 0.3). How many hits each one takes is decided by game code, not by this table. `rrfaku` uses `STRONG`: resistant, not unbreakable.
- `CAR_GLASS_OPAQUE` (124) is the non-see-through variant.
- The four flag values are raw columns. Which is which is only given in the garbled column header of the file, so the positions are unconfirmed.
